# C Code Dataset

This dataset contains small C programs along with line-by-line explanations of what each line does. Each example resides in the `c_examples` directory and is accompanied by a corresponding `*_explanation.md` file.

## Contents

- `hello.c` – a simple hello world program.
- `factorial.c` – recursive factorial computation.
- `array_sum.c` – compute sum and average of an integer array.
- `bubble_sort.c` – demonstration of bubble sort.
- `quicksort.c` – implementation of quicksort sorting algorithm.

For each `.c` file, there is a matching explanation file describing the function of each line.
